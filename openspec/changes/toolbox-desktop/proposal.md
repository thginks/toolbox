# 跨平台桌面工具箱

## Why

开发者在日常工作中需要频繁切换不同的在线工具来处理 JSON、Cron 表达式等任务，这不仅效率低下，还存在数据隐私风险。我们需要一个本地运行的轻量级工具箱，让开发者能够快速访问常用工具，同时保证数据安全。

## 背景与动机

开发者在日常工作中经常需要使用各种小工具，如 JSON 格式化、Cron 表达式生成、密码生成等。目前这些工具分散在不同的网站和应用中，切换成本高，且很多在线工具存在隐私和安全问题。

需要一个**轻量级、快速启动、跨平台**的桌面工具箱，将常用开发工具集成在一起，提供统一的使用体验。

## 核心需求

### 功能需求

**MVP（第一阶段）**
1. **JSON 格式化工具**
   - JSON 美化（格式化）
   - JSON 压缩（压缩为一行）
   - 语法高亮显示
   - 行号显示
   - 支持大文件处理（>10MB）

**后续阶段**
2. **JSON 对比工具**
   - 两个 JSON 的差异对比
   - 高亮显示差异
   - 支持树形结构对比

3. **Cron 生成解析器**
   - 可视化 Cron 表达式生成
   - Cron 表达式解析
   - 下次执行时间计算

4. **密码生成器**
   - 自定义密码长度
   - 字符类型选择（大小写、数字、特殊字符）
   - 批量生成
   - 强度评估

### 非功能需求

**性能要求**
- **启动速度**：< 500ms（目标），< 1s（可接受）
- **内存占用**：< 100MB（空闲状态）
- **包大小**：< 20MB（Windows），< 15MB（Linux）

**用户体验**
- **界面风格**：简洁现代，类似 VS Code 风格
- **主题支持**：浅色模式 + 深色模式
- **响应式**：窗口大小自适应
- **快捷键**：支持常用操作的快捷键

**数据管理**
- **配置持久化**：主题、窗口大小、工具设置
- **历史记录**：JSON 格式化历史（可选，后续添加）
- **导入导出**：配置导入导出（可选）

**架构要求**
- **插件化**：工具以插件形式存在，按需加载
- **跨平台**：Windows 10+ 和 Debian 13
- **可扩展**：方便未来添加新工具

## 技术约束

### 必须使用
- **Tauri 2.x**：桌面应用框架
- **Vue 3 + TypeScript**：前端框架
- **Vite**：构建工具

### 推荐使用
- **Tailwind CSS**：样式开发
- **Pinia**：状态管理
- **VueUse**：工具函数库

### 禁止使用
- **Electron**：包体积过大，不符合轻量级要求
- **jQuery**：与 Vue 3 不兼容

## 成功标准

### 功能标准
1. JSON 格式化工具能正确处理各种合法 JSON
2. 支持至少 10MB 的 JSON 文件
3. 界面响应流畅，无卡顿

### 性能标准
1. 冷启动时间 < 1s
2. 工具切换时间 < 100ms
3. 内存占用稳定，无内存泄漏

### 用户体验标准
1. 界面简洁直观，无需说明书
2. 主题切换无缝，无闪烁
3. 跨平台体验一致

## 范围排除

### 第一阶段不包含
- 用户账户系统
- 云端同步
- 移动端版本
- 命令行集成
- 多语言支持（仅中文）

### 明确不做
- 在线协作功能
- 付费功能
- 广告或推广
